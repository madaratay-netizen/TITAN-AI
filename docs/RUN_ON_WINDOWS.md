# تشغيل ADWIN OS على ويندوز 🚀

## ✅ أسهل طريقة — ضغطة واحدة
في مجلد المشروع، **اعمل دبل كليك على:**

```
Run-ADWIN-OS.bat
```

وخلاص! الملف ده هيعمل كل حاجة لوحده:
1. يشغّل **Ollama** (محرك الشات والبحث والتخطيط).
2. يشغّل **ComfyUI** (توليد الصور) — لو متثبّت.
3. يشغّل **خادم ADWIN OS**.
4. يفتح **الداشبورد** في المتصفح تلقائياً على `http://127.0.0.1:8077`.

> آمن تشغّله أكتر من مرة — بيتخطّى أي حاجة شغّالة أصلاً.

## ⏹️ إيقاف التشغيل
اقفل **النوافذ المصغّرة** (python) اللي اسمها ADWIN و ComfyUI، أو اقفل الجهاز عادي.

## 🧩 اللي بيشتغل مع الأداة
| الخدمة | المنفذ | بتعمل إيه | لازمة؟ |
|---|---|---|---|
| ADWIN backend | 8077 | الأداة والداشبورد | ✅ أساسي |
| Ollama | 11434 | شات · RAG · تخطيط المشاهد | ✅ للشات/الصور الهندسية |
| ComfyUI | 8188 | توليد الصور بالذكاء | اختياري |

## 🆕 أول مرة على جهاز جديد (تثبيت)
لو نقلت المشروع لجهاز جديد، اعمل التثبيت مرة واحدة من الـ Terminal في مجلد المشروع:

```bash
python -m venv .venv
.\.venv\Scripts\pip install -r requirements.txt
```

وتثبيت [Ollama](https://ollama.com) + موديل:
```bash
ollama pull qwen3.5:4b
```

وللصور (اختياري): شغّل `scripts/install_comfyui.sh` على لينكس، أو ثبّت ComfyUI يدوياً في مجلد `..\ComfyUI` جنب مجلد المشروع. وبعدها `Run-ADWIN-OS.bat` هيلاقيه ويشغّله.

## 🔧 لو حاجة مش شغّالة
- **الصور مش بتتولّد؟** تأكد إن ComfyUI شغّال (نافذة python على المنفذ 8188).
- **الشات مش بيرد؟** تأكد إن Ollama شغّال، وإن فيه موديل متثبّت (`ollama list`).
- **الصفحة مش بتفتح؟** استنى شوية وافتح يدوياً `http://127.0.0.1:8077`.
- **مش بيشتغل الفيديو/الصوت؟** جرّب تفتح الملف من مجلد `storage\workspace\` في مشغّل عادي (VLC).
