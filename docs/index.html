أفكار واستخدامات

تقدر تستخدمه في إيه؟

أفكار عملية تبدأ بيها على طول.

  • مساعد بحث في مستنداتك — اسأل أسئلة ويجاوب بالمصدر (تقنية RAG).
  • إنتاج فيديو تعريفي/إعلاني — فكرة → مشاهد → تعليق صوتي → MP4.
  • تفريغ الاجتماعات — تسجيل → نص + ترجمة (Speech-to-Text).
  • مساعد برمجة آمن — يكتب ويشرح، وما ينفّذ إلا بموافقتك.
  • توليد صور للمحتوى — من وصف نصي (Stable Diffusion).
  • تعليق صوتي احترافي — أي نص → صوت (Text-to-Speech).
  • تشخيص جهازك وشبكتك — أدوات IT دفاعية.
  • مساعد شخصي أوفلاين — تلخيص، كتابة، أفكار… بدون نت.

يشتغل على أنهي أجهزة؟

بيصنّف جهازك لمستويات، وكل مستوى بيفتح مميزات أكتر — حتى الجهاز البسيط بيشتغل.

🔵 قياسيرامات 8–16 جيجاشات أكبر + RAG + برمجة
🟣 متقدمرامات 16–32 جيجاموديلات أكبر + RAG موسّع
🟠 مبدعكارت شاشة 6 جيجا+توليد صور + فيديو قصير
🔴 استوديوكارت شاشة 12 جيجا+فيديو متقدم + دقّات عالية

3 خطوات

# 1) تقرير جهازك (بدون أي تثبيت):
python scripts/adwin_report.py

# 2) تثبيت المتطلبات:
pip install -r requirements.txt

# 3) تشغيل ADWIN وفتح الواجهة:
uvicorn backend.app.main:app --host 127.0.0.1 --port 8077
# ثم افتح:  http://127.0.0.1:8077
